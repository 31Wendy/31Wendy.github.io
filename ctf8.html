# Bugku CTF - 聪明的小羊

## 题目信息
- 平台：Bugku
- 类型：Crypto
- 考点：栅栏密码（2栏）

## 1. 现象观察
题目描述给出密文：`fa{fe13f590lg6d46d0d0}`，提示“翻过了2个栅栏”。

## 2. 利用过程
1. 将密文分成两半：
- 前半：`fa{fe13f590`
- 后半：`lg6d46d0d0}`
2. 交叉读取两段字符，拼成明文。

```python
cipher = "fa{fe13f590lg6d46d0d0}"
half = len(cipher)//2
flag = "".join(a+b for a,b in zip(cipher[:half], cipher[half:]))
print(flag)
