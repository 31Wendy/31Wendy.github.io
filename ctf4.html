# Bugku CTF - 你必须让他停下

## 题目信息
- 平台：Bugku
- 类型：Web
- 考点：JS 定时器干扰、抓包

## 1. 现象观察
访问环境后，页面不断刷新/跳动，无法看清内容。

## 2. 利用过程
方法一：Burp Suite 抓包
- 开启代理，拦截请求。
- 反复点击 Forward，逐次收集返回的字符串片段。
- 拼接得到完整 Flag。

方法二：禁用 JavaScript
- F12 -> Ctrl+Shift+P -> Disable JavaScript。
- 刷新页面，页面静止，直接显示 Flag。

方法三：清除定时器
- F12 控制台输入 `for(let i=1;i<9999;i++) clearInterval(i)`。
- 页面停止刷新，查看 DOM。

## 3. 结果
Flag: flag{********}

## 4. 总结
前端 JS 定时器只是干扰手段，通过抓包或禁用 JS 即可绕过。
